# TaskFlow — Bug Hunt Challenge 🐛

Welcome to your first task at the company!

## Your Mission

This is a real-world internal tool that our team built. It has some **known issues** that slipped through code review.
Your job is to **find and fix them**.

## The App

**TaskFlow** is a simple task management dashboard. It has:
- A login page (`index.html`)
- A task dashboard (`dashboard.html`)
- Shared styles (`style.css`)
- JavaScript logic (`app.js`, `dashboard.js`)

> Demo credentials: `admin@taskflow.io` / `admin123`

## Rules

- You have **2 hours**
- Fix the bugs **directly in the files** — no framework rewrites
- Document each bug you find in a `FIXES.md` file you create:
  - What the bug is
  - Where it is (file + line)
  - What you changed to fix it
  - Why it was a problem
- There are bugs across **HTML, CSS, and JavaScript**
- There may be **more than one issue in a single file**

## What We Are Looking For

- Can you **spot issues** without being told where they are?
- Can you **explain** why something is a bug, not just fix it?
- Do you understand the **security implications** of certain bugs?
- Do you fix things the **right way** or just make it "stop throwing errors"?


Good luck. 🚀
